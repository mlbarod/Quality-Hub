# 품질 포털 요구사항

## 목표

여러 경로에 흩어진 공정 품질 지표와 관리 Rule을 한곳에서 빠르게 조회하고 시각화한다. 공정·부서별 Q&A 게시판을 통해 사용자와 관리 담당자의 문의 및 답변을 체계적으로 관리한다.

## 사용자와 권한

- 역할: 일반 사용자, 공정별 담당자, 품질 총괄, 시스템 관리자
- 인증: 사내 SSO
- 권한: 포털에서 역할과 담당 공정·부서를 별도 관리
- 데이터, 문서, 검색 결과 및 게시판 열람 범위는 포털 권한을 기준으로 제한

## 주요 기능

### 품질 대시보드

- 여러 원천의 품질 지표를 일관된 화면에서 시각화
- 핵심 지표의 정의와 계산식은 추후 확정
- 품질 총괄이 지표 요구사항을 정의하고 개발자가 계산 로직과 차트를 구현
- 새로고침할 때 원천 데이터의 최신 변경 사항 반영
- 원천 조회 실패 시 마지막 정상 데이터, 정상 수집 시각 및 연동 오류 표시

### 통합 검색 및 Rule 관리

- 공유 폴더 파일과 문서 URL의 본문을 포함한 통합 검색
- 결과에 출처, 담당 공정, 문서 유형, 수정 시각 및 원문 연결 정보 제공
- 공정 담당자가 관리 Rule을 직접 등록·수정
- 모든 변경 이력과 이전 버전 보존

### Q&A 게시판

- 공정·부서별 공개 게시판
- 해당 조직 담당자가 답변과 처리 상태 관리
- 품질 총괄과 시스템 관리자는 전체 게시판 관리
- 포털 내부 알림 제공

## 데이터 원천

- 사내 저장소의 Parquet 파일
- 사내 DB의 특정 테이블
- 공유 폴더 문서
- 문서 URL

원천별 연결 방식은 교체 가능한 연동 구조로 설계하며, 데이터 출처와 동기화 상태를 추적할 수 있어야 한다.

## UI 및 품질 기준

- Supabase 메인 화면의 깔끔하고 세련된 디자인 언어를 전체 서비스에 일관되게 적용
- 넓은 여백, 명확한 정보 위계, 절제된 색상, 모듈형 카드와 반응형 레이아웃 활용
- Supabase의 상표, 로고 또는 고유 화면은 복제하지 않음
- 초기 사용자 약 50명 기준으로 모든 주요 화면을 3초 이내에 표시
- 요구 기능과 성능·보안·접근성 검증을 완료한 후 공개 가능

## 1차 범위 제외

- 이메일 및 사내 메신저 알림
- 관리자가 계산식과 차트를 직접 생성하는 기능
- 관리 Rule 게시 전 별도 승인 절차

## 미확정 항목

- 핵심 품질 지표와 계산식
- 데이터 원천별 스키마, 경로 및 접속 규격
- SSO 연동 규격
- 검색할 문서 형식과 추출 정책
- 최종 배포 환경과 사내 보안 기준

초기에는 로컬 환경에서 기능과 성능을 검증하고, 실제 배포 환경은 이후 결정한다.
