# 품질 포털 요구사항

## 목표

여러 경로에 흩어진 공정 품질 지표와 관리 Rule을 한곳에서 빠르게 조회하고 시각화한다. 공정·부서별 Q&A 게시판을 통해 사용자와 관리 담당자의 문의 및 답변을 체계적으로 관리한다.

## 사용자와 권한

- 역할: 마스터, 관리자, 일반유저
- 인증: 사내 SSO
- 권한: 마스터가 사용자 및 권한 화면에서 사내 ID를 기준으로 관리자 권한을 추가·삭제
- 일반유저: 사내 인증을 통해 기본 접근하며 대규모 일반유저 목록은 권한 관리 화면에 표시하지 않음
- 데이터, 문서, 검색 결과 및 게시판 열람 범위는 포털 권한을 기준으로 제한

## 주요 기능

### 품질 대시보드

- 여러 원천의 품질 지표를 일관된 화면에서 시각화
- 핵심 지표의 정의와 계산식은 추후 확정
- 마스터 또는 관리자가 지표 요구사항을 정의하고 개발자가 계산 로직과 차트를 구현
- 새로고침할 때 원천 데이터의 최신 변경 사항 반영
- 원천 조회 실패 시 마지막 정상 데이터, 정상 수집 시각 및 연동 오류 표시

### 각종 Report 조회

- 품질 Hub의 Report를 업무 카테고리와 카드 형식으로 구성하고 검색·필터 제공
- 권한이 있는 사용자가 Report 이름, 설명, 카테고리와 Spotfire 연결 정보를 등록·관리
- Report 선택 시 데이터를 별도 가공하지 않고 Spotfire Web Player 원본 화면 표시
- Spotfire의 화면 구성과 조회 권한을 유지하며 실제 URL·인증 방식은 연동 단계에서 확정

### 품질 Agent

- 사내 자체 LLM 서비스를 API로 연결하여 GPT형 대화 기능 제공
- 기본 우측 대화 패널에서 사용하고 필요할 때 전체 작업 화면으로 확장
- 실제 API 규격, 인증과 Report 참조 범위는 연동 단계에서 확정

### 통합 검색 및 Rule&SOP 관리

- 공유 폴더 파일과 문서 URL의 본문을 포함한 통합 검색
- 결과에 출처, 담당 공정, 문서 유형, 수정 시각 및 원문 연결 정보 제공
- Rule&SOP 앱은 변승위 Category분류와 Rule&SOP의 두 영역으로 구성
- Rule&SOP는 대분류·중분류·소분류 필터에 따라 해당 범위의 카드를 배치
- 공정 담당자가 Rule과 SOP를 직접 등록·수정
- 모든 변경 이력과 이전 버전 보존

### Q&A 게시판

- 공정·부서별 공개 게시판
- 해당 조직 담당자가 답변과 처리 상태 관리
- 마스터와 관리자는 전체 게시판 관리
- 포털 내부 알림 제공

## 데이터 원천

- 사내 저장소의 Parquet 파일
- 사내 DB의 특정 테이블
- 공유 폴더 문서
- 문서 URL

원천별 연결 방식은 교체 가능한 연동 구조로 설계하며, 데이터 출처와 동기화 상태를 추적할 수 있어야 한다.
데이터 원천의 연결 정보와 동기화 설정은 별도 DB에서 관리하며 포털 UI에 데이터 원천 관리 화면을 제공하지 않는다.

## UI 및 품질 기준

- Supabase 메인 화면의 깔끔하고 세련된 디자인 언어를 전체 서비스에 일관되게 적용
- 넓은 여백, 명확한 정보 위계, 절제된 색상과 모듈형 카드 활용
- Supabase의 상표, 로고 또는 고유 화면은 복제하지 않음
- PC 데스크톱 화면만 지원하며 모바일·태블릿 반응형 화면은 개발 범위에서 제외
- 별도 교육 없이 주요 기능을 쉽게 찾고 사용할 수 있는 정보 구조 제공
- 초기 사용자 약 50명 기준으로 모든 주요 화면을 3초 이내에 표시
- 요구 기능과 성능·보안·접근성 검증을 완료한 후 공개 가능

## 1차 범위 제외

- 이메일 및 사내 메신저 알림
- 관리자가 계산식과 차트를 직접 생성하는 기능
- Rule&SOP 게시 전 별도 승인 절차

## 미확정 항목

- 핵심 품질 지표와 계산식
- 데이터 원천별 스키마, 경로 및 접속 규격
- SSO 연동 규격
- 검색할 문서 형식과 추출 정책
- 최종 배포 환경과 사내 보안 기준

초기에는 로컬 환경에서 기능과 성능을 검증하고, 실제 배포 환경은 이후 결정한다.
