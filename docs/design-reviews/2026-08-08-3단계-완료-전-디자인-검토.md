## 대상 변경과 환경

디자인 관련 미커밋 변경 파일은 `prototype/app.js`, `prototype/index.html`, `prototype/styles.css`, `prototype/src/qna.css`, `prototype/src/qna/QnaApp.jsx`다. 전체 미커밋 파일 목록과 diff는 같은 작업 상태의 Git 기록으로 확인했으며, 검토 후 디자인에 영향을 주는 추가 수정은 하지 않았다.

- 브라우저: Chromium 149 Headless
- 기본 화면: 1920×1080, DPR 1, 배율 100%
- 선택 화면: 1440×900은 최초 검토에서만 확인했으며 최종 보정 후 재검증하지 않음
- 동작 축소: `prefers-reduced-motion: reduce`
- 역할·데이터: 로컬 가상 데이터와 목업 역할 전환
- 제외: 실제 SSO, DB, Spotfire, 사내 LLM, 운영 네트워크와 운영 성능

## 발견 사항과 후속 계획

### DR-P3-01 · 필수 흐름과 125% 확대 미검증

- 근거 상태: `미검증`
- 우선순위: 게이트 필수 항목
- 영향: 기능이 구현됐더라도 확대 시 잘림·겹침과 검색·알림 도착 흐름을 독립 근거로 보장할 수 없음
- 원인: 브라우저 실행이 84초 이상 응답하지 않아 독립 검토 중단
- 계획: 동일 작업 상태에서 125% 확대, 검색 세 목적지와 도착 초점, 답변 후 알림 증가를 독립 재검토하고 메인 개발자가 결과를 다시 대조

### DR-P3-02 · 초기 로딩 성능 편차

- 근거 상태: `확인`
- 우선순위: `P1`
- 영향: 개발 환경에서 최초 화면 체감 속도가 일정하지 않을 수 있음
- 근거: 로컬 Vite `load` 약 2.45~6.08초, 독립 측정 5.626초와 50ms 초과 긴 작업 반복
- 담당: 메인 개발자
- 반영 시점: 5단계 성능 검증 전
- 계획: 프로덕션 미리보기에서 초기 렌더링과 Q&A 지연 로딩을 최적화하고 냉간·온간 반복 측정 후 독립 재검토

## 메인 개발자 재검증

메인 개발자는 현재 작업 상태에서 다음을 별도로 확인했다.

- 통합 검색 기본 결과 28건(Report 12, Rule&SOP 8, Q&A 8)
- Rule&SOP 등록 후 9건과 검색 반영, 새로고침 후 복원
- Q&A 답변 등록, 알림 생성과 읽지 않은 알림 수 변경, 새로고침 후 복원
- 최신 홈·통합 검색 자동 접근성 위반 0건과 콘솔 처리되지 않은 예외 0건
- Node 계약 테스트 54건과 React 테스트 4건 통과

이 결과는 기능 회귀가 없다는 보완 근거다. 독립 검토의 필수 미검증을 대신하지 않으므로 전체 판정은 `보류`로 유지한다.
