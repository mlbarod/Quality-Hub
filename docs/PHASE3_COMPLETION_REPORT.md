# Quality Hub 3단계 진행 보고서

**구현 범위:** 가상 데이터 기반 로컬 기능  
**검토 일자:** 2026-08-08  
**판정:** `부분 완료` — 기능 구현·자동 테스트는 완료했으나 독립 디자인 게이트는 `보류`

## 1. 결과

실제 사내 데이터를 제공받지 않는 조건에서 재현 가능한 가상 데이터로 Rule&SOP, Q&A, 내부 알림과 통합 검색의 주요 기능을 로컬에서 사용할 수 있도록 구현했다. 변경 내용은 현재 브라우저에 저장되어 새로고침 후에도 유지된다.

실제 DB·Parquet의 스키마가 확정되지 않았으므로 현재 로컬 데이터 규격을 운영 호환 규격으로 판정하지 않는다. 최종 사내 데이터 연결 시점인 4단계에서 실제 필드, 자료형, 키와 제약 조건을 기준으로 검증하고 조정한다.

## 2. 구현 내용

### 가상 데이터 저장 계층

- 데이터 종류별 저장 키와 규격 버전을 분리
- 저장소를 사용할 수 없는 브라우저에서는 현재 실행 중인 메모리로 안전하게 대체
- 손상됐거나 규격 버전이 다른 데이터는 가상 초기값으로 대체
- 실제 연동 어댑터로 교체할 수 있도록 화면 상태와 저장 처리를 분리

### Rule&SOP

- 등록·수정·숨김·복구와 개정 이력을 로컬 저장
- 신규 등록과 수정 결과를 카드, 상세, 분류 필터와 통합 검색에 즉시 반영
- 새로고침 후 문서와 개정 이력 복원

### Q&A와 내부 알림

- 질문, 답변·댓글, 상태, 최종 답변, 숨김·복구와 변경 이력을 로컬 저장
- 답변 등록, 상태 변경과 최종 답변 지정 시 가상 내부 알림 생성
- 읽음 상태와 알림 수를 저장하고 헤더·알림 화면에 반영

### 통합 검색

- 고정된 검색 결과 대신 현재 Report, Rule&SOP와 Q&A 가상 데이터를 조합
- 등록·수정·숨김과 Q&A 변경 결과를 검색에 즉시 반영
- 검색 결과에서 각 콘텐츠 화면으로 이동하는 기존 흐름 유지

## 3. 검증 결과

- `npm test`: Node 계약 테스트 54건, React 테스트 4건 통과
- `npm run build`: Vite 프로덕션 빌드 통과
- `git diff --check`: 통과
- 실제 브라우저: 기본 검색 결과 28건(Report 12, Rule&SOP 8, Q&A 8) 확인
- 실제 브라우저: Rule&SOP 신규 등록 후 9건 저장, 검색 반영과 새로고침 복원 확인
- 실제 브라우저: Q&A 답변과 알림 생성, 읽지 않은 알림 수 변경과 새로고침 복원 확인
- 최신 홈·통합 검색 자동 접근성 검사: 위반 0건
- 브라우저 콘솔의 처리되지 않은 예외: 0건
- `npm audit --omit=dev`: 알려진 운영 의존성 취약점 0건

완료 전 독립 디자인 재검토에서는 1920×1080 환경의 홈 배치, 12px 안내 문구, 40px 이상 질문 등록 버튼과 Rule 필터의 동작 축소 보정을 확인했다. 그러나 125% 확대와 통합 검색 세 목적지·Q&A 답변 후 알림 흐름을 독립 검토자가 끝내지 못해 디자인 게이트는 `보류`다. 메인 개발자의 브라우저 기능 검증은 이를 보완하지만 독립 검토의 미검증을 대체하지 않는다. 상세 내용은 [완료 전 디자인 검토 보고서](design-reviews/2026-08-08-3단계-완료-전-디자인-검토.md)를 따른다.

1920×1080 개발 서버와 CDP 검증 환경에서 `load`는 약 2.45~6.08초로 편차가 컸고 50ms를 넘는 긴 작업이 반복 관찰됐다. 따라서 3초 기준은 `미통과`가 아니라 이 단계에서 안정적으로 확인되지 않은 `미검증`으로 판정한다. 약 50명 동시 사용이나 운영 성능 근거가 아니며, 초기 렌더링과 Q&A 지연 로딩 최적화는 5단계 성능 검증 전까지 남은 위험으로 관리한다.

## 4. 현재 경계와 남은 위험

- 로컬 저장은 현재 브라우저에만 적용되며 사용자·브라우저·PC 사이에 공유되지 않는다.
- 역할 전환은 실제 SSO 인증이나 서버 권한 집행이 아니다.
- 첨부파일은 이름과 크기만 표시하는 가상 항목이며 파일 본문을 저장하지 않는다.
- 실제 DB·Parquet 스키마, 경로, 접속 권한과 동기화 규칙은 `미검증`이다.
- 실제 Spotfire, 사내 LLM, 공유 폴더, 문서 URL과 SSO는 연결하지 않았다.
- 운영 보안, 동시 사용자 부하와 운영 네트워크 성능은 `미검증`이다.
- 125% 확대와 통합 검색 세 목적지·Q&A 답변 후 알림 흐름은 독립 디자인 재검토가 필요하다.

독립 디자인 미검증 항목을 다시 확인한 뒤 3단계 완료 여부를 재판정한다. 실제 연동 항목은 4단계, 운영 품질 검증은 5단계에서 수행한다.
