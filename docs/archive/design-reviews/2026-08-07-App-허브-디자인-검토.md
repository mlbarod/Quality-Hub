# App 허브 디자인 검토

> 보고서 상태: `만료`
> 이 보고서 이후 App 카드·글자·Agent 크기와 배치에 영향을 주는 변경이 추가됐다. 현재 화면의 통과 근거로 사용할 수 없으며 새 독립 검토가 필요하다.

## 검토 개요

- 검토 일시: 2026-08-07 KST
- 대상: 스카이 톤 App 허브, 별도 대시보드 전환, 중앙 품질 Agent와 업무 상세 화면
- 데이터 경계: 예시 데이터 기반 로컬 UI 목업. 실제 SSO·DB·Spotfire·사내 LLM과 운영 환경은 미연동
- 독립 검토 판정: `보류`
- 메인 개발자 재검증 판정: `조건부 통과`

독립 디자인 검토에서는 P0가 없었으나 브라우저 연결이 반복 종료되어 필수 화면 일부가 `미검증`으로 남았다. 메인 개발자가 별도 정상 브라우저 세션에서 누락 범위를 재검증하고 확인된 P1·P2를 수정했다. 로컬 최초 표시 성능과 실제 운영 성능은 제한사항으로 남긴다.

## 실행 환경과 범위

- Chromium 149, DPR 1, 100% 배율
- 화면 크기: 1366×768, 1440×900, 1920×1080
- 일반 동작과 `prefers-reduced-motion: reduce`
- 화면: 홈, 대시보드, 품질 Agent 패널, Report, 통합 검색, Rule&SOP, Q&A, 사용자 및 권한
- 기존 추적·미추적 변경을 보존했으며 검토 에이전트는 저장소를 수정하지 않음

## 독립 검토 발견 사항과 반영

### DR-HUB-FINAL-01 · App 보조 정보 가독성

- 근거 상태 / 우선순위: `확인` / `P1`
- 발견: App 상태와 Agent 보조 문구가 8px로 작아 빠르게 읽기 어려움
- 반영: App과 Agent 보조 문구를 10px로 확대하고 자간을 조정함
- 재검증: 1366×768과 1920×1080에서 카드 겹침·잘림 없이 표시됨

### DR-HUB-FINAL-02 · 홈 소개 문장 줄바꿈

- 근거 상태 / 우선순위: `확인` / `P2`
- 발견: 소개 문장이 음절 단위로 어색하게 나뉨
- 반영: 문장을 간결하게 다듬고 문장 사이에 의도한 줄바꿈을 적용함
- 재검증: 1366×768과 1920×1080에서 두 문장이 자연스럽게 분리됨

## 메인 개발자 재검증

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| 홈 배치 | 통과 | 세 화면 크기에서 네 사선형 App, 중앙 Agent와 연결선의 겹침·잘림 없음 |
| 대시보드 분리 | 통과 | 버튼 선택 후 `homeHidden=true`, `dashboardHidden=false`, `aria-pressed=true`, `#dashboard` 확인 |
| 화면 톤 | 통과 | Dashboard·Agent·Report·Rule&SOP·Q&A·권한 화면을 실제 브라우저에서 스카이·화이트 톤으로 확인 |
| 동작 축소 | 통과 | 연결 신호, Agent 링, 대시보드 전환의 계산된 `animation-name`이 모두 `none` |
| 자동 접근성 | 통과 | 홈 전체 axe 위반 0건 |
| 콘솔 안정성 | 통과 | 프로덕션 미리보기 재로딩 중 오류·처리되지 않은 예외 0건 |
| 자동 테스트 | 통과 | Node 계약·서버 테스트 49개와 Vitest 통과 |
| 빌드 | 통과 | Vite 프로덕션 빌드 성공 |
| 표시 성능 | 부분 완료 | 재방문 로드 2.09초. 캐시 비활성 로컬 FCP 약 3.29초로 3초 목표를 근소하게 넘음 |
| 운영 성능·보안 | 미검증 | 약 50명 동시 사용, 사내 네트워크와 실제 연동 환경은 현재 목업 범위 밖 |

## 최종 판정과 남은 위험

P0는 없고 독립 검토의 P1·P2는 반영·재검증했으므로 이번 UI 변경은 `조건부 통과`로 판정한다. 홈과 업무 진입 흐름은 요청 범위를 충족한다. 다만 최초 표시 3초 목표는 로컬 측정에서 근소하게 초과했으며 운영 환경 성능은 확인하지 않았다. 실제 공개 전 프로덕션 배포 조건에서 초기 표시, 키보드 전수 순회, 약 50명 부하와 실제 연동 보안을 다시 검증해야 한다.
